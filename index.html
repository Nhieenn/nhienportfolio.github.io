Bullet Hell: Pixel Survival

Game Rogue-like sinh tồn đạn đạo 2D. Ứng dụng kiến trúc Unity 6 UI Toolkit (UXML/USS) thay thế uGUI, tối ưu 3–5 Draw Calls và bản địa hóa 5 ngôn ngữ.

UI/UX & Client Dev
Chi tiết & Link
• Vai trò & Module xây dựng:

UI/UX Engineer & Client Developer: Xây dựng toàn bộ hệ thống giao diện (Main Menu, Loadout & Upgrade, Shop, Daily Quests, Settings, Pause, Game Over/Win-Loss, HUD, Tutorial Film Reel) bằng Unity 6 UI Toolkit (UXML + USS + C#). Tích hợp Firebase Auth ngầm trong màn hình Loading.

• Giải pháp kỹ thuật nổi bật:
  • UI Toolkit & 3-Layer Pixel Art: Giảm Draw Calls từ 40–80 xuống chỉ 3–5 Draw Calls/màn hình nhờ Auto-Batching và Sprite Atlas. Cách ly animation trên GPU Matrix Transform, duy trì mượt mà 60 FPS.
  • Event-Driven / EventBus Pattern: Kết nối lỏng (Loose Coupling) giữa UI với Gameplay, Audio, Quest; loại bỏ hoàn toàn [SerializeField]/FindObject, triệt tiêu lỗi NullReferenceException.
  • Bản địa hóa Reactive (5 Ngôn ngữ): Nạp từ điển JSON (Việt, Anh, Tây Ban Nha, Nhật, Trung), đổi ngôn ngữ tức thì không cần reload Scene.
  • Chống vỡ Layout CJK & Font Fallback Chain: Flexbox thích ứng, Dynamic SDF Font Atlas xử lý triệt để lỗi ô vuông (□ - Tofu character) trên mobile.
  • Gatekeeper Pattern: Tự động kiểm duyệt dữ liệu chuỗi thô và kích hoạt từ điển tiếng Anh dự phòng (Anti-Leak Fallback) khi gặp sự cố mạng.

Blue Square 2D

Endless Runner / Platformer tốc độ cao. Ứng dụng Generic Object Pooling, tối ưu Game Feel (Coyote Time, Jump Buffering) và Dynamic Theme.

Gameplay & Systems
Chi tiết & Link
• Vai trò & Module xây dựng:

Unity Gameplay & Systems Developer: Lập trình Core Mechanics & Game Feel với cơ chế Coyote Time & Jump Buffering, hỗ trợ đa nền tảng New Input System (Keyboard, Touch, Mouse). Xây dựng ThemeManager đổi màu thế giới thời gian thực (Ngày → Chiều → Đêm) theo điểm số, độ khó gameSpeed tăng dần và Cinemachine Impulse Camera Shake.

• Giải pháp kỹ thuật nổi bật:
  • Generic Object Pooling (UnityEngine.Pool): Áp dụng Generic Dictionary ObjectPool cho toàn bộ chướng ngại vật (ObstacleSpawner), triệt tiêu hoàn toàn Instantiate/Destroy trong game loop và loại bỏ hiện tượng GC Spike.
  • Platformer Game Feel Optimization: Tính toán chính xác coyoteTime (cho phép nhảy sau khi rời mép đất) và jumpBufferTime (nhận trước lệnh nhảy), loại bỏ cảm giác input drop.
  • Dynamic Color Cycle (Color.Lerp / HDR): Thuật toán nội suy màu toán học theo thang điểm, tự động cập nhật đồng bộ màu sắc của Camera Background, Sprite Renderers và Particle Systems.
  • Seamless Infinite Scrolling & UI Toolkit: Cuộn nền vô tận sử dụng Mathf.Repeat kết hợp Sprite Bounds (GroundScroller). Sử dụng UI Toolkit tạo menu hiện đại và animation nhấp nháy kỷ lục mới.
