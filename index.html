Bullet Hell

Trò chơi Rogue-like sinh tồn 2D. Xây dựng toàn bộ hệ thống giao diện bằng Unity 6 UI Toolkit thế hệ mới, tối ưu hóa mức tiêu thụ còn 3–5 Draw Calls và tích hợp engine bản địa hóa 5 ngôn ngữ thời gian thực.

Tech Stack: Unity 6 · UI Toolkit (UXML/USS) · EventBus · Firebase Auth
Metrics: 3–5 Draw Calls / màn hình · 60 FPS Stable Mobile
UI/UX & Client Developer
Chi tiết kỹ thuật

Phạm vi thực hiện

Thiết kế và lập trình hoàn chỉnh hệ thống Client UI (Main Menu, Loadout & Upgrade, Shop, Daily Quests, Settings, Pause, Game Over/Win-Loss Flow, HUD, Interactive Tutorial) bằng Unity 6 UI Toolkit (UXML + USS + C#). Tích hợp module xác thực ngầm Firebase Auth trong quy trình nạp dữ liệu.

Giải pháp kỹ thuật nổi bật

  • Tối ưu hóa UI Rendering: Kết hợp UI Toolkit Auto-Batching và Sprite Atlas, cô lập chuyển động trên GPU Matrix Transform; giảm tải từ 40–80 lệnh vẽ xuống 3–5 Draw Calls/màn hình, giải phóng CPU và duy trì 60 FPS.
  • Kiến trúc Event-Driven (EventBus): Xây dựng kênh điều phối sự kiện phân tán giữa UI, Gameplay, Audio và Quests; loại bỏ hoàn toàn tham chiếu trực tiếp ([SerializeField] / FindObject), triệt tiêu lỗi NullReferenceException.
  • Hệ thống Bản địa hóa 5 Ngôn ngữ: Nạp từ điển JSON thời gian thực (Việt, Anh, Tây Ban Nha, Nhật, Trung). Xử lý vỡ layout chữ tượng hình CJK bằng Flexbox và Dynamic SDF Font Atlas; tích hợp Fallback Chain sang tiếng Anh khi mất kết nối mạng.

Core Gameplay & Simulation Developer

Phạm vi thực hiện

Lập trình hệ thống Nông trại & Chăn nuôi (chu kỳ sinh trưởng cây trồng, vật nuôi, suy giảm trạng thái), Hệ thống Xây dựng & Quy hoạch lưới 3D (BuildGridManager), Đồng bộ dữ liệu Offline theo Unix Timestamp, Giao diện Mobile UI Toolkit và Rigging dụng cụ vào Humanoid Animator.

Giải pháp kỹ thuật nổi bật
