Kiến Trúc & Tiêu Chuẩn Lập Trình

01

Clean Architecture & Patterns

Tránh bẫy code Spagetti và lạm dụng `Update()`. Áp dụng các Design Patterns cốt lõi để code dễ bảo trì, dễ mở rộng:

  • ▪ Observer / Action: Event-driven decoupled UI
  • ▪ State Machine: Player & Enemy State Control
  • ▪ Object Pooling: Tái sử dụng GameObject
02

Performance & UI Optimization

Hiệu năng ổn định là ưu tiên số một cho game di động và máy yếu:

  • ▪ Canvas Isolation: Tách Canvas tĩnh/động
  • ▪ Sprite Atlas: Giảm thiểu tối đa Draw Calls
  • ▪ Profiler Profiling: Đo lường Memory & Garbage Collection
03

Workflows & Collaboration

Kinh nghiệm làm việc nhóm và hoàn thành đúng deadline cam kết:

  • ▪ Git Flow: Branching, pull request & resolve conflict
  • ▪ Multi-platform: Build và test Windows, WebGL, Android
  • ▪ Data-driven: Tách biệt Game Designer qua ScriptableObject
